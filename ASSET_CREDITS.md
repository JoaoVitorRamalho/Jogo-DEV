## Dependências pesquisadas e não incorporadas nesta entrega

| Recurso | Motivo |
|---|---|
| The Pixel Nook — Retro RPG Overworld / Character Pack | Pacotes itch.io com fluxo de download que não pôde ser concluído automaticamente aqui; não misturar com ArMM1998 sem revisão visual |
| maciaz — Pokémon-like Top Down Tile Set | itch.io; crédito obrigatório; não baixado nesta fase |
| Ninja Adventure (pixel-boy) | CC0, mas o repositório GitHub público traz só o demo Godot; o zip completo no itch.io exige chave de download interativa |

## Nota sobre Pokémon

Jornada é um fan game. Nomes, tipos e a história de Asteria referenciam o universo Pokémon. Não foram usadas artes oficiais da Nintendo, Game Freak ou The Pokémon Company.
