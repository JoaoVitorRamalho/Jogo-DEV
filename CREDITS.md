# Créditos — Jornada (Asteria)

**Uso:** projeto de fã entre amigos, sem monetização nem publicação comercial.

## Código e roteiro

- Repositório: [JoaoVitorRamalho/Jogo-DEV](https://github.com/JoaoVitorRamalho/Jogo-DEV)
- Roteiro-mestre: `GERO.md`, `data/campaign.ts`, `data/cities.ts`

## Sprites de Pokémon

- [PokeAPI / sprites](https://github.com/PokeAPI/sprites) — imagens `public/assets/sprites/pokemon/` (script `build_assets.py`)
- The Pokémon Company / Nintendo — personagens e nomes (fã game privado)

## Mundo e tiles

- **ArMM1998** — tileset nature CC0 (via `.tmp-art`)
- Tiles extras gerados em `scripts/build_assets.py`

## Personagens (overworld)

- **Liberated Pixel Cup** — [Universal LPC Spritesheet Character Generator](https://github.com/LiberatedPixelCup/Universal-LPC-Spritesheet-Character-Generator)
- Atribuição por peça conforme combinação usada em `scripts/download_assets.py`

## Áudio

- Faixas CC0 baixadas por `scripts/download_assets.py` (RPG chip / fontes listadas no script)

## Packs opcionais (`public/vendor/`)

- **Kenney** — CC0 quando presente (Tiny Dungeon etc.)
- **OpenGameArt** — licença por pack; ver README dentro de cada pasta
- Download: `python scripts/fetch_vendor_assets.py` ou manual conforme `GERO.md`

## Fontes UI

- **VT323** — Google Fonts (layout Next.js). A Silkscreen deixava o W ilegível.
